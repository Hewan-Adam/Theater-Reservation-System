 Theatre Reservation System (C++)

 Overview
The Theatre Reservation System is a C++ console-based application designed to manage movie seat reservations efficiently.  
It allows customers to book seats and print tickets, while administrators can manage reservations, track income, and view system data.
The project demonstrates practical usage of multiple data structures in a real-world scenario, making it suitable for **DSA coursework and academic projects.


 Features

 Customer Functions
- Book single or multiple seats for a selected movie
- Choose between Normal and VIP seats
- Print tickets immediately after booking
- View personal booking summary
- Automatic handling of full seats using a waiting list

 Admin Functions
- Display all reservations with full details
- Sort reservations by booking ID using Merge Sort
- View total income generated from all bookings
- Update movies available on each screen
- View screen connectivity graph


 Data Structures Used

Data Structure   Purpose 
 Linked List     Store all reservations dynamically |
 Stack           Undo seat booking operations |
 Queue           Manage waiting list when seats are full |
 Graph           Represent connectivity between screens |
 Hash Table      Fast customer lookup by name |
