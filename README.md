 1. Overview
The Theatre Reservation System is a C++ console application that allows customers to book seats for movies and enables administrators to manage reservations efficiently. The system includes advanced features such as ticket printing, booking summary, fast customer lookup using a hash table, and total income tracking.
The program uses multiple data structures to demonstrate practical applications:
•	Linked List – to store reservations dynamically
•	Stack – to allow undoing seat bookings
•	Queue – to manage a waiting list
•	Graph – to show connectivity between screens
•	Hash Table – to speed up customer searches

2. Features
Customer Functions
•	Book single or multiple seats for a selected movie
•	Print tickets immediately after booking
•	View personal booking summary
Admin Functions
•	Sort reservations by booking ID (Merge Sort)
•	Display all reservations with details
•	View total income from all bookings
•	Update movies on each screen
•	View the connectivity graph of screens
Pricing
•	Normal Seat: 100 Birr
•	VIP Seat: 200 Birr

3. Data Structures Used
Data Structure	Purpose
Linked List	Store all reservations dynamically
Stack	Undo seat booking operation
Queue	Waiting list for customers when seats are full
Graph	Screen connectivity visualization
Hash Table	Fast customer search by name
